## 核心技术架构

WgetCloud 的技术架构是其稳定性的基石：

| 技术项   | 详情                               | 优势解读                                        |
| :------- | :--------------------------------- | :---------------------------------------------- |
| **入口** | 广东 BGP、上海 BGP 多线接入        | 自动选择最优入口，无视宽带运营商限制            |
| **专线** | IEPL/IPLC 双线专线（广港、沪日等） | 走陆地/海底光缆专线，不经过公网防火墙，极低延迟 |
| **加速** | 亚马逊 Global Accelerator          | AWS 官方链路加速，敏感期依然坚挺稳定            |
| **协议** | Trojan（主力）；路由器支持 SSR     | 流量完美伪装成 HTTPS，免受防火墙干扰与封锁      |
| **面板** | 自研面板，非通用机场面板           | 安全防黑客，支持分组管理与智能负载              |
| **落地** | 59+ 纯净 IP，覆盖 19 个国家和地区  | 解锁能力强，规避 IP 被封锁的尴尬                |

### 为什么选择 Trojan 协议？

WgetCloud 早期曾支持 SS/SSR/VMess 等多种协议，后逐步统一为 **Trojan**。原因在于：

- **伪装性强**：Trojan 流量伪装为正常 HTTPS 流量，更难被识别
- **性能优越**：相比 VMess 等协议，Trojan 加解密开销更小
- **稳定性高**：在敏感时期的存活能力更强
